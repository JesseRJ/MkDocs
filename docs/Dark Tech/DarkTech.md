# About

This project was for a Studio named 'Dark Tech'. Its main focus was to have us students look at the ethical side of technology and then go deeper into the negative side or dark side.

## Project theme

The project was done in a group of 5 students and the subject my group had was themed 'The Punishing Home'. The main goal of this theme was to make an installation that would shock the user and confront them with how a smart system, in a dark tech setting, could react/handle towards the user.
