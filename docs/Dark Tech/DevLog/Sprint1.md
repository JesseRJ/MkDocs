# Sprint 1 - Design Process

## Sprint Overview

This was the very first sprint where we as a team had to start to get to know each other and had to begin with a direction for the project. During the Sprint we made the base concept of the provocatype we wanted to work on and did an individual analysis on a topic related to the project. For me that analysis was about uninhabitability and it can be found [here](../Analysis/Uninhabitability.md)

### Sprint Goals

For this sprint the other N3 and I decided to take the lead during the project and we discussed that we should start with a design. The reason for this was that we would have to make an installation as a final provocatype and therefore needed to start with a good design to use as the base of the idea. This would help with having something solid that could be expanded with extra small things to bring the project together.

So the goal for this Sprint was to have a base to work from and to brainstorm what we could bring together in Sprint 2.

### Planning

The planning for this sprint was to start with individual drawings so we could come together and pickout parts we loved from each drawing to then continue on to making a small prototype in 2 groups. But starting with individual drawings could result in to big of a difference in what needed to be done so we started with a brainstorm session and a moodboard, so we would be more on the same line but still be able to have individual idea's.

## Research & Exploration

During the Brainstorm and moodboard session i had a difficult time to come with ideas as I could not place my self in the correct mindset. It took me a bit to feel some creativity but the others came with ideas and this helped with me being able to feel more ideas coming up.
